# 모로가도 · 바톤 상세페이지 v10

첨부한 `상세페이지1(1).svg`의 **좌하단 폴더 네임택**만 추가한 버전입니다. v9의 페이지 전환 및 바톤로그 인터랙션 코드는 그대로 유지했습니다.

## 실행

`index.html`을 브라우저에서 엽니다. `styles.css`, `app.js`, `assets/`의 폴더 구조를 유지하세요. 별도 설치나 외부 JavaScript 라이브러리는 필요하지 않습니다.

별도로 제공된 `morogaro-baton-v10.html`은 이미지·CSS·JavaScript를 모두 포함한 단일 실행 파일입니다. 수정 후 `python build.py`를 실행하면 동일한 방식의 단일 파일을 생성합니다.

폰트는 이전 버전과 동일한 Spoqa Han Sans Neo 웹폰트를 불러옵니다. 최초 로딩에는 인터넷 연결이 필요합니다. 폰트 파일은 포함하지 않았습니다.

## 이번에 추가한 디자인

새 SVG의 `Union` 레이어와 `filter0_d_3421_2586` 그림자를 그대로 분리해 `assets/detail-folder-nametag.svg`로 사용합니다. 경로 좌표, 흰색 채움, 그림자 필터는 원본과 동일합니다. PNG 변환·손실 압축·경로 단순화·재작도는 하지 않았습니다.

원본 1440 × 1024 프레임에서 탭 상단은 y=946이며, 그림자를 포함한 표시 영역은 x=0, y=940, 폭 1440, 높이 84입니다. 추가 SVG의 viewBox는 `0 940 1440 84`이며, HTML에서는 left=0, top=940에 원래 크기로 표시합니다. 원본에서 프레임 밖으로 나간 부분만 동일한 프레임 경계로 잘라 표시합니다.

기존 `바톤 너머` 버튼의 텍스트·위치·클릭 영역은 바꾸지 않았습니다. 네임택 배경은 장식 요소이므로 클릭을 가로채지 않습니다. 버튼을 누르면 기존처럼 아래 로그 페이지로 이동합니다.

네임택은 상세페이지와 함께 이동하고, 전환이 끝난 로그 페이지에는 남지 않습니다. 위로 돌아오면 다시 나타납니다.

## 변경하지 않은 부분

- 바톤로그 JavaScript 전체: `app.js`는 v9와 바이트 단위로 동일합니다. 개발용 `Morogaro.version` 값도 인터랙션 코어 버전인 `9.0.0`을 그대로 유지합니다.
- 3초 순차 진입, 뒤로 갈수록 빨라지는 속도, 오른쪽 60px 출발 경계, 메인 바톤 고정.
- 가로 관련 바톤 / 세로 하위 계승의 선택·휠·드래그 움직임.
- 900ms 양방향 페이지 전환, 안내창 호버 동작.
- 기존 이미지·SVG 45개, 상세정보·파일 목록, 갤러리, 버튼, 댓글, 미리보기.
- 기존 화면의 좌표·여백·크기·폰트·색상 및 고정 1440px 레이아웃 정책.

## 검증

`verification.json`에 이번 버전의 26개 검사 결과를 기록했습니다. `asset-integrity-v10.json`에는 기존 이미지의 SHA-256 대조와 새 벡터의 원본 일치 여부가 있습니다.

Chromium에서 단일 HTML을 로드해 확인했습니다. 최초 화면은 기존 v9와 비교했을 때 y=940~1024의 새 네임택 영역만 달라졌고, 전환이 끝난 로그 화면은 동일한 픽셀로 렌더링됐습니다. 새 배경 벡터만 따로 비교했을 때도 원본 레이어와 렌더링이 일치했습니다.

1440×1024, 1280×800, 1920×1080에서 기존 요소의 위치·크기를 비교했습니다. 버튼 클릭, 아래/위 페이지 전환, 호버 진입, 가로/세로 바톤 탐색, 파일 탭과 이미지 전환도 확인했습니다.

비교를 일정하게 하기 위해 검증 시 외부 폰트 요청을 차단했습니다. 원격 Spoqa 폰트의 실제 렌더링, Safari, 실제 Mac 트랙패드 테스트는 이번 검증 범위에 포함되지 않습니다. 폰트 연결 및 인터랙션 구현 자체는 v9와 동일합니다.
