# 모로가도 실제 사이트로 배포하기 (GitHub Pages + 구글 Apps Script)

비용: **0원**(GitHub · 구글) + **AI 사용료**(1명당 약 20~30원, 하루 상한으로 묶임). 잠드는 서버가 없어요.

```
QR → GitHub Pages (화면 · 파일 읽기, 항상 켜짐)
        └→ 구글 Apps Script (무료) ─┬→ OpenAI (AI 추천 · 키는 여기 숨김)
                                    └→ 구글 시트(기록) · 드라이브(캡처)
```

---

## 1. 구글 시트 + Apps Script (10분)

1. Claude가 만들어 둔 구글 시트 **`모로가도 사용성 평가`**를 열어요. 없다면 새 스프레드시트를 만들어도 돼요.
2. 메뉴 **확장 프로그램 → Apps Script**를 눌러요.
3. 기본 코드를 지우고 `deploy/apps-script/Code.gs` 내용을 통째로 붙여넣은 뒤 저장(💾)해요.
4. 왼쪽 **⚙ 프로젝트 설정 → 스크립트 속성 → 스크립트 속성 추가**를 눌러요.
   - `OPENAI_API_KEY` = `sk-...`(2단계에서 만든 키)
   - `AI_DAILY_LIMIT` = `300`(선택, 하루 AI 상한)
5. 편집기로 돌아와 함수 선택 칸에서 `연결_테스트`를 고르고 **실행**을 눌러요.
   - 권한 창이 뜨면 본인 계정 → **고급 → (안전하지 않음)으로 이동 → 허용**을 눌러요. 내가 만든 스크립트라 괜찮아요.
6. **배포 → 새 배포 → 유형 선택(⚙) → 웹 앱**을 골라요.
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
   - **배포**를 누르면 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해서 Claude에게 알려주세요.

## 2. OpenAI API 키 (10분)

1. https://platform.openai.com 에서 **Billing**으로 가서 5달러를 충전해요.
2. **Limits**에서 월 한도를 걸어요(예: 10달러).
3. **API keys → Create new secret key**를 눌러 나온 값을 1단계 4번의 스크립트 속성에만 넣어요. 사이트 코드나 채팅에는 붙여넣지 않아요.

## 3. 사이트 켜기 (Claude가 GitHub에 올린 뒤, 1분)

1. GitHub 저장소 → **Settings → Pages**로 가요.
2. **Build and deployment → Source: Deploy from a branch**, **Branch: `main` / `/(root)`**로 맞추고 **Save**를 눌러요.
3. 1~2분 뒤 `https://아이디.github.io/morogaro/` 주소가 생겨요. 이 주소로 QR을 만들어요.

## 4. 확인

1. 휴대폰으로 주소를 열고 파일을 올려 끝까지 진행한 뒤 **바톤 만들기**를 눌러요.
2. 구글 시트를 확인해요.
   - `진행 기록` 탭: 방문자 한 줄
   - `바톤 완성` 탭: 입력값 · 소요 시간 · 캡처 링크
3. 드라이브 `모로가도 사용성 평가` 폴더에 캡처 두 장과 `기록.json`이 있으면 끝이에요.

## 운영 팁

- **기록이 안 쌓일 때:** Apps Script 편집기 왼쪽 **실행** 메뉴에서 오류를 볼 수 있어요.
- **Apps Script 코드를 고친 뒤:** **배포 → 배포 관리 → ✏ → 버전: 새 버전 → 배포**를 눌러야 반영돼요. 주소는 그대로예요.
- **AI 상한·키 바꾸기:** 스크립트 속성에서 값만 바꾸면 바로 적용돼요.
- **비용 확인:** OpenAI 대시보드 **Usage**에서 볼 수 있어요.
- **이탈 분석:** `진행 기록` 시트에서 필터를 켜고 `상태` 열로 `이탈 (…)`만 모아 보세요.
- **사이트에서 읽는 파일 범위:**
  - 이미지 · PDF(앞 40쪽 본문, 앞 8쪽 미리보기) · 텍스트 계열은 내용까지 읽어요.
  - AI(PDF 호환 저장) · PSD(합쳐진 이미지 · 텍스트 레이어 글꼴)도 내용을 읽어요. DOCX 등은 이름 · 형식만 확인해요.
  - 파이썬 서버(`server.py`)는 로컬 실험용으로 남겨 뒀어요.
