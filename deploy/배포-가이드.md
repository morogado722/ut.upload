# 모로가도 실제 사이트로 배포하기

비용: **서버 0원(Render 무료)** + **AI 사용료**(1명당 약 20~30원, 하루 상한으로 묶여 있음) + **구글 시트·드라이브 0원**

```
방문자 휴대폰 ──QR──▶ Render 서버(사이트 + AI 분석)
                         ├─▶ OpenAI (파일 읽고 정보 추천)
                         └─▶ 구글 Apps Script ─▶ 구글 시트(기록) + 드라이브(캡처)
```

---

## 1. OpenAI API 키 만들기 (10분)

1. https://platform.openai.com 에 로그인해요.
2. **Billing**에서 크레딧을 5달러 정도 충전해요.
3. **Limits**에서 월 사용 한도를 걸어요(예: 10달러). 한도를 넘어도 사이트는 멈추지 않고, AI 없이 파일에서 직접 정보를 뽑는 방식으로 바뀌어요.
4. **API keys** → **Create new secret key**를 눌러 나온 `sk-...` 값을 메모장에 잠깐 복사해 둬요. 이 값은 4단계에서 Render에만 넣고, 다른 곳에는 절대 붙여넣지 않아요.

## 2. 구글 시트 + 기록 수신기 만들기 (10분)

1. 구글 드라이브에서 새 **구글 스프레드시트**를 만들고 이름을 `모로가도 사용성 평가`로 바꿔요.
2. 메뉴 **확장 프로그램 → Apps Script**를 열어요.
3. 기본으로 들어 있는 코드를 지우고, 이 폴더의 `apps-script/Code.gs` 내용을 통째로 붙여넣어요.
4. 맨 위 `const TOKEN = '여기에-비밀값을-넣어주세요';`의 따옴표 안을 아무도 모를 긴 문자열로 바꿔요(예: `morogaro-2026-x7Qk2pLm9v`). 이 값도 메모해 둬요.
5. 저장(💾)한 뒤, 위쪽 함수 선택 칸에서 `연결_테스트`를 고르고 **실행**을 눌러요.
   - 권한 허용 창이 뜨면 본인 계정 → **고급 → (안전하지 않음)으로 이동 → 허용**을 눌러요. 내가 만든 스크립트라 괜찮아요.
   - 시트에 `진행 기록`, `바톤 완성` 탭이 생기고, 드라이브에 `모로가도 사용성 평가` 폴더가 생기면 성공이에요.
6. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**을 골라요.
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
   - **배포**를 누르면 나오는 `https://script.google.com/macros/s/.../exec` 주소를 복사해 둬요.

## 3. GitHub에 올리기 (10분)

파일이 200개가 넘어서 웹 화면 끌어다 놓기(최대 100개)보다 **GitHub Desktop** 앱이 편해요.

1. https://github.com 에 가입하고, https://desktop.github.com 에서 GitHub Desktop을 설치해요.
2. GitHub Desktop → **File → Add local repository**에서 이 프로젝트 폴더(`morogaro-merged`)를 고르고, "저장소를 만들까요?"에 **create a repository**를 눌러요.
3. **Publish repository**를 누르고, **Keep this code private**는 체크해 둬도 괜찮아요.
4. `.env` 파일과 `research-logs` 폴더는 `.gitignore`에 적혀 있어서 자동으로 빠져요.

## 4. Render에 배포하기 (15분)

1. https://render.com 에 GitHub 계정으로 가입해요(카드 등록 없이 무료).
2. **New + → Blueprint**를 누르고, 3단계에서 만든 저장소를 골라요. 이 폴더의 `render.yaml` 설정을 자동으로 읽어요.
3. 입력 칸이 세 개 나와요.
   - `OPENAI_API_KEY`: 1단계의 `sk-...`
   - `RESEARCH_WEBHOOK_URL`: 2단계의 `https://script.google.com/.../exec`
   - `RESEARCH_TOKEN`: 2단계 4번에서 정한 비밀값(Apps Script의 TOKEN과 똑같이)
4. **Apply**를 누르면 5~10분 동안 설치한 뒤 `https://morogaro-xxxx.onrender.com` 주소가 생겨요.

## 5. 확인하기

1. 휴대폰과 컴퓨터로 주소를 열어요. 아래에 **사용성 연구 안내**가 뜨면 **동의하고 시작**을 눌러요.
2. 파일을 올리고 끝까지 진행해 **바톤 만들기**를 눌러요.
3. 1분 안에 구글 시트에 이렇게 남으면 성공이에요.
   - **진행 기록** 탭: 내 세션 한 줄(상태 `완성`)
   - **바톤 완성** 탭: 입력값 · 소요 시간 · 캡처 링크
   - 드라이브 폴더: `업로드 페이지.jpg`, `상세페이지.jpg`, `기록.json`

## 6. QR 코드

배포 주소를 알려주면 Claude가 QR 이미지를 만들어 줄 수 있어요. 직접 만들려면 크롬 주소창의 공유 → **QR 코드 만들기**를 써도 돼요.

## 운영 팁

- **잠든 서버:** 무료 서버는 15분 동안 아무도 안 쓰면 잠들고, 다음 사람이 들어올 때 깨어나는 데 1분쯤 걸려요(그동안 로딩 화면이 보여요).
  - 평가 직전에 직접 한 번 열어 두면 돼요.
  - 전시 기간 내내 바로 떠야 하면 그 달만 Render 요금제를 **Starter(월 $7)**로 올렸다가 끝나면 Free로 내리세요.
- **하루 AI 상한:** 기본 300회예요. Render → Environment에서 `AI_DAILY_LIMIT` 값을 바꾸면 돼요(0이면 상한 없음).
- **비용 확인:** OpenAI 대시보드 **Usage**에서 날짜별 사용 금액을 볼 수 있어요.
- **기록 보기:** 시트에서 필터를 켜고 `상태` 열로 `이탈 (…)`만 모으면 어느 단계에서 많이 나갔는지 바로 보여요. `진행 기록`에는 바톤을 끝까지 안 만든 사람도 모두 남아요.
- **동의하지 않은 사람:** 아무것도 저장되지 않아요. 올린 원본 파일은 동의한 사람 것도 저장하지 않아요(파일 이름 · 종류만).
- **자체 도메인을 연결하면:** Render → Environment에 `ALLOWED_HOSTS=내도메인.com`을 추가해요.
- **Apps Script 코드를 고치면:** 배포 → 배포 관리 → 연필 → 버전 **새 버전** → 배포를 눌러야 반영돼요(주소는 그대로예요).
